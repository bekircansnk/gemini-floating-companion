# Gemini Floating Companion - APK Sürümleri

Bu dizin, derlenen resmi ve açık kaynak APK dağıtımlarını içerir:

1. **`GeminiCompanion-v1.1.0-clean-opensource.apk`**:
   - **Tüm kullanıcılar ve açık kaynak topluluk içindir.**
   - İçerisinde hiçbir gömülü API anahtarı veya token **BULUNMAZ**.
   - Uygulama ilk açıldığında doğrudan "Özel Gemini API Anahtarı" alanına kendi ücretsiz Google AI Studio API anahtarınızı girerek kullanabilirsiniz.

2. **`GeminiCompanion-v1.1.0-debug.apk`**:
   - Geliştirici ortamında test için kullanılan yerel derleme.
